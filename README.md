# Odds rollover calculator

A one-page calculator: type a stake, odds per day and number of days, and see what
happens if you roll everything over or bet the same stake daily – and the real chance of it.

**Live page:** https://stayclassic45.github.io/odds-calculator/ (after GitHub Pages is turned on)

## Turn on the free web link (once)
1. In this repo click **Settings** → **Pages**.
2. Under **Build and deployment**, set **Source** to "Deploy from a branch".
3. Choose branch **main** and folder **/ (root)**, then **Save**.
4. Wait 1–2 minutes and refresh: the link appears at the top of the Pages screen.

The page holds no keys, no picks and no personal data; your last inputs are saved
only in your own browser.
